# Ten-hour submission freeze

Do not add new product features after this point. Accept only a reproducible
bug fix, an authorized evidence update or a submission-blocking correction.

## Hours 10–8: freeze and capture

- Use commit `404c098` or its latest documentation-only successor.
- Confirm the live URL and repository open in a private/incognito window.
- Run one 500-future Extreme path and optimizer.
- Capture Living Twin, Risk, Strategy, Proof and Method screenshots.
- Preserve a screen recording of the complete judge path.

## Hours 8–6: record

- Record the 4:25 pitch from `PITCH_SCRIPT_4_MINUTES.md`.
- Record the 45-second fallback separately.
- Keep the strongest take; do not chase cinematic perfection.
- Verify spoken claims against the live UI before uploading.

## Hours 6–4: assemble submission

- Paste `SUBMISSION_PORTAL_COPY.md` into the portal.
- Add final team identity and video URL.
- Use only the Vercel URL and GitHub repository listed there.
- Confirm the portal preview contains no draft placeholders.

## Hours 4–2: hostile rehearsal

- Perform two timed demos without reading the script.
- Answer every question in `JUDGE_QA.md` in one breath.
- Practice the internet-failure path using the screenshots/video.
- Remove any step that repeatedly causes confusion.

## Hours 2–1: final verification

- Confirm HTTPS live page, repository visibility and video permissions.
- Check audio from another device or account.
- Save screenshots of the completed portal and every submitted URL.
- Do not deploy cosmetic changes.

## Final hour: submit early

- Submit no later than 45 minutes before the deadline.
- Save the receipt, confirmation email and final portal screenshot.
- Keep the live application untouched after submission.
